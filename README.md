# B2carrent
รถเช่าและระบบหลังบ้าน — B2 Motorcycle & Car Rental (นครศรีธรรมราช)

React 18 + Vite + Tailwind CSS + lucide-react

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```

## โครงสร้าง
```
src/
  data.js                 ข้อมูลตัวอย่าง (รถ, การจอง, บริการเสริม, โค้ดส่วนลด, FAQ, รีวิว)
  lib/pricing.js          คำนวณวันเช่า, ส่วนลด, เช็กรถว่างตามช่วงวัน
  lib/promptpay.js        สร้าง PromptPay QR payload มาตรฐาน EMVCo (สแกนจากแอปธนาคารได้จริง)
  lib/supabase.js         เชื่อมต่อ Supabase (ใช้เมื่อตั้งค่า VITE_SUPABASE_URL / VITE_SUPABASE_ANON_KEY)
  lib/api/                ชั้นข้อมูลกลาง: remote.js = ฐานข้อมูลคลาวด์, local.js = โหมดเดโมในเบราว์เซอร์
  lib/storage.js          เก็บค่าเฉพาะเครื่อง (รายการโปรด, เบอร์ที่เคยจอง)
supabase/
  schema.sql              ตาราง, สิทธิ์การเข้าถึง (RLS), ฟังก์ชันจอง/คำนวณราคาฝั่งเซิร์ฟเวอร์, ที่เก็บรูป
  seed.sql                ข้อมูลเริ่มต้น (รถ 6 คัน, การตั้งค่าร้าน, โค้ดส่วนลด, ราคาบริการเสริม)
scripts/make-seed.mjs     สร้าง seed.sql ใหม่จาก src/data.js
  components/             Header, Toast, Modal, StatusBadge
  customer/               หน้าบ้าน: Hero/ค้นหา, ฟลีตรถ, จอง+ชำระเงิน, ติดตามสถานะ, FAQ/รีวิว/ที่เที่ยว
  admin/                  หลังบ้าน: Dashboard, ตารางคิวรถ, รายการจอง, จัดการฟลีต, ตั้งค่า
```

## ฟีเจอร์หลัก
**หน้าบ้าน**
- ค้นหารถว่างตามวัน-เวลารับ/คืน (ตรวจจับคิวทับซ้อน), ปุ่มเลือก 1/3/7 วัน
- กรองตามประเภท/หมวด, ค้นหา, เรียงราคา/รีวิว, รายการโปรด ♥
- จอง 3 ขั้นตอน: บริการเสริม → PromptPay QR (นับถอยหลัง + แนบสลิป) → ใบยืนยัน (พิมพ์/PDF)
- ส่วนลดอัตโนมัติ เช่า 3 วัน -5%, 7 วัน -15% + โค้ด `B2DRIVE2026` (10%), `EVGREEN` (15% เฉพาะ EV)
- ติดตามสถานะแบบ timeline, แนบสลิปภายหลัง, ยกเลิกการจอง
- ขั้นตอนการจอง, รีวิว, เอกสารที่ต้องใช้, FAQ, footer ข้อมูลร้าน, ปุ่ม Facebook/LINE/โทรลอย, เมนูมือถือ
- ลิงก์แฟนเพจ Facebook (เปิดในแท็บใหม่ / แอป Facebook บนมือถือ) แก้ไขได้ที่หลังบ้าน → ตั้งค่าระบบ

**หลังบ้าน**
- Dashboard: รายได้, รายได้ตามประเภท, กราฟการใช้งาน ±7 วัน, สถานะการจอง, คิวส่ง/รับรถวันนี้, รถใกล้เช็กระยะ
- ตารางคิวรถ (Gantt 14 วัน)
- รายการจอง: กรองสถานะ, ค้นหา, ส่งออก CSV, รายละเอียด+สลิป, flow Pending → Confirmed → Picked Up → Completed
- จัดการฟลีต: เพิ่ม/แก้ไข/ลบ (กันลบรถที่มีคิวค้าง), เลขไมล์และรอบเช็กระยะ
- รูปรถเช่า: เลือกจากไฟล์/คลังภาพ (หลายรูปพร้อมกัน, ลากวางได้), ถ่ายจากกล้องมือถือ (เปิดกล้องหลังทันที) หรือเว็บแคมบนคอมพิวเตอร์, วาง URL, ตั้งรูปหลัก/เรียงลำดับ/ลบ — ระบบย่อรูปเหลือไม่เกิน 1000px อัตโนมัติ (สูงสุด 8 รูปต่อคัน)
- ตั้งค่า: PromptPay (พรีวิว QR), ข้อมูลร้าน, LINE OA, จัดการโค้ดส่วนลด, รีเซ็ตข้อมูลเดโม

> หมายเหตุ: LINE Notify ปิดให้บริการตั้งแต่ 31 มี.ค. 2025 — การแจ้งเตือนควรใช้ LINE Messaging API จากฝั่งเซิร์ฟเวอร์

## ฐานข้อมูลกลาง (ทุกเบราว์เซอร์/ทุกเครื่องเห็นข้อมูลเดียวกัน)

เว็บมี 2 โหมด:
- **โหมดคลาวด์ (Supabase)** — เมื่อตั้งค่า `VITE_SUPABASE_URL` และ `VITE_SUPABASE_ANON_KEY` ข้อมูลรถ รูป การจอง สลิป และการตั้งค่า อยู่บนฐานข้อมูลกลาง แอดมินต้องล็อกอินก่อนเข้าหลังบ้าน
- **โหมดเดโม** — ถ้าไม่ได้ตั้งค่า ข้อมูลอยู่ในเบราว์เซอร์นั้นเท่านั้น (หลังบ้านจะแสดงป้าย "โหมดเดโม")

### ขั้นตอนตั้งค่า (ทำครั้งเดียว ~15 นาที)
1. สมัครที่ https://supabase.com → **New project** (Region แนะนำ *Southeast Asia (Singapore)*) ตั้งรหัสผ่านฐานข้อมูลแล้วเก็บไว้
2. เมนู **SQL Editor** → New query → วางเนื้อหาไฟล์ `supabase/schema.sql` → **Run**
3. New query อีกครั้ง → วาง `supabase/seed.sql` → **Run** (ใส่รถ 6 คันและการตั้งค่าร้านเริ่มต้น)
4. สร้างบัญชีแอดมิน: เมนู **Authentication → Users → Add user → Create new user** ใส่อีเมล/รหัสผ่านของเจ้าของร้าน (ติ๊ก *Auto Confirm User*)
5. ให้สิทธิ์แอดมิน: กลับไป **SQL Editor** แล้วรัน (เปลี่ยนอีเมลเป็นของคุณ)
   ```sql
   insert into public.admins (user_id)
   select id from auth.users where email = 'owner@example.com';
   ```
6. ปิดการสมัครสมาชิกเอง: **Authentication → Sign In / Providers → ปิด "Allow new users to sign up"** (ให้มีแต่บัญชีที่คุณสร้างเอง)
7. คัดลอกคีย์: **Project Settings → API** → *Project URL* และ *anon public key*
8. ใส่คีย์:
   - เครื่องตัวเอง: คัดลอก `.env.example` เป็น `.env.local` แล้วใส่ค่า → `npm run dev`
   - เว็บจริง (Vercel / Netlify / Cloudflare Pages ฯลฯ): เพิ่ม Environment Variables ชื่อ `VITE_SUPABASE_URL` และ `VITE_SUPABASE_ANON_KEY` แล้ว **Deploy ใหม่** (ค่าเหล่านี้ถูกฝังตอน build)
9. เปิดเว็บ → หลังบ้าน → ล็อกอิน → ควรเห็นป้าย "ข้อมูลกลางบนคลาวด์"

> `anon key` เปิดเผยได้ (ออกแบบมาให้อยู่ในหน้าเว็บ) ความปลอดภัยมาจากสิทธิ์ใน `schema.sql` — **ห้าม** ใส่ `service_role key` ในหน้าเว็บเด็ดขาด

### ความปลอดภัยที่ตั้งไว้ใน schema.sql
- ลูกค้าทั่วไปอ่านได้แค่ข้อมูลรถและข้อมูลร้าน — ดูรายการจอง/โค้ดส่วนลดของคนอื่นไม่ได้
- ราคาคำนวณใหม่บนเซิร์ฟเวอร์ทุกครั้ง (แก้ราคาจากหน้าเว็บไม่ได้) และกันจองซ้อนวันเดียวกัน
- ค้นหาสถานะการจองต้องใช้เบอร์โทรที่จอง (รหัสจองอย่างเดียวไม่พอ)
- สลิปโอนเงินเก็บในที่เก็บส่วนตัว เฉพาะแอดมินเปิดดูได้
- แก้ไขรถ/ราคา/การตั้งค่า/สถานะการจอง ได้เฉพาะบัญชีที่อยู่ในตาราง `admins`

### ข้อมูลเดิมในโหมดเดโม
ข้อมูลที่เคยแก้ในเบราว์เซอร์ (โหมดเดโม) จะไม่ถูกย้ายขึ้นคลาวด์อัตโนมัติ — หลังเชื่อมต่อแล้ว ให้เพิ่ม/แก้รถและรูปใหม่ผ่านหลังบ้านครั้งเดียว ข้อมูลจะเห็นตรงกันทุกเครื่อง
