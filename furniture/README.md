# Furniture
ร้านเฟอร์นิเจอร์ออนไลน์และระบบหลังบ้าน

React 18 + Vite + Tailwind CSS + lucide-react + Supabase (โครงสร้างเดียวกับ B2carrent)

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # ไฟล์สำหรับขึ้นเว็บอยู่ใน dist/
```

## หน้าเว็บ
| ลิงก์ | หน้า |
|---|---|
| `/` | หน้าร้าน: สินค้า, ค้นหา, กรองหมวด, ตะกร้า, สั่งซื้อ |
| `/#track` | ลูกค้าติดตามคำสั่งซื้อ (ใช้เบอร์โทร) แนบสลิป / ยกเลิก |
| `/#admin` | หลังบ้าน (ไม่มีปุ่มให้ลูกค้าเห็น — เปิดด้วยลิงก์นี้) |

## ฟีเจอร์
**หน้าร้าน**
- สินค้าแยกหมวด (ห้องนั่งเล่น ห้องนอน ห้องทานอาหาร ห้องทำงาน นอกบ้าน ของตกแต่ง), ค้นหา, เรียงราคา, ราคาลด, สินค้าหมด
- หน้ารายละเอียดสินค้า: หลายรูป, วัสดุ/ขนาด/สี, จำนวนคงเหลือ
- ตะกร้าเก็บไว้ในเครื่อง, ค่าจัดส่ง + ส่งฟรีเมื่อซื้อครบยอด
- สั่งซื้อ → PromptPay QR ตามยอดจริง → แนบสลิป → ส่งรายละเอียดทาง LINE ของร้าน
- ติดตามสถานะ: รอตรวจสอบ → ยืนยันแล้ว → จัดส่งแล้ว → สำเร็จ

**หลังบ้าน**
- ภาพรวม: ยอดขายวันนี้/เดือนนี้, คำสั่งซื้อที่ต้องดำเนินการ, สินค้าใกล้หมด
- คำสั่งซื้อ: ค้นหา/กรอง, ดูสลิป, เปลี่ยนสถานะ, บันทึกเลขพัสดุ, ส่งออก CSV, อัปเดตทันทีเมื่อมีออเดอร์ใหม่
- สินค้า: เพิ่ม/แก้ไข/ซ่อน/ลบ, อัปโหลดรูปสูงสุด 8 รูป (ย่ออัตโนมัติ), จัดลำดับรูป, สต็อก, สินค้าแนะนำ
- ตั้งค่าร้าน: ชื่อร้าน, เบอร์, LINE OA, Facebook, ที่อยู่, PromptPay (พรีวิว QR), ค่าจัดส่ง

## ฐานข้อมูล (Supabase)
ใช้โปรเจกต์ Supabase เดียวกับ B2carrent (บัญชีฟรีสร้างได้สูงสุด 2 โปรเจกต์) แต่แยกข้อมูลกันชัดเจน:
ตาราง `furniture_products`, `furniture_orders`, `furniture_settings`, `furniture_admins` และที่เก็บไฟล์ `furniture-photos`, `furniture-slips`
— ไม่แตะข้อมูลรถเช่าเลย

- `supabase/schema.sql` — ตาราง, สิทธิ์ (RLS), ฟังก์ชันสั่งซื้อฝั่งเซิร์ฟเวอร์, ที่เก็บรูป
- `supabase/seed.sql` — ข้อมูลร้านเริ่มต้น + สินค้าตัวอย่าง 8 รายการ + ให้แอดมิน B2 เป็นแอดมินร้านนี้ด้วย

**แอดมิน:** ล็อกอินด้วยอีเมล/รหัสผ่านเดียวกับหลังบ้าน B2 Rental ได้ทันที
ถ้าต้องการเพิ่มคนอื่น สร้างผู้ใช้ใน Supabase → Authentication แล้วรัน
```sql
insert into public.furniture_admins (user_id) select id from auth.users where email = 'staff@example.com';
```

### ความปลอดภัย
- ราคาและค่าส่งคำนวณใหม่บนเซิร์ฟเวอร์ทุกครั้ง แก้ราคาจากหน้าเว็บไม่ได้
- ตัดสต็อกตอนสั่งซื้อแบบล็อกแถว (ไม่ขายเกินจำนวน), ยกเลิกแล้วคืนสต็อกอัตโนมัติ
- ค้นหาคำสั่งซื้อต้องใช้เบอร์โทรที่สั่ง, สลิปเก็บแบบส่วนตัว เฉพาะแอดมินเปิดดูได้
- `anon key` ในโค้ดเปิดเผยได้ — **ห้าม** ใส่ `service_role key` ในหน้าเว็บ
