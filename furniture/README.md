# Furniture Design · FORMA STUDIO
เว็บออกแบบเฟอร์นิเจอร์ (ตู้ ตู้ครัว โต๊ะ เตียง) แบบ 2D/3D พร้อมใบตัดไม้ ต้นทุน ใบเสนอราคา และจัดผังห้อง
(เก็บค่าบริการการใช้งานรายวัน — ไม่ได้ขายสินค้า)

React 18 + Vite + Tailwind CSS + lucide-react + three.js + Supabase (โครงสร้างเดียวกับ B2carrent)

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # ไฟล์สำหรับขึ้นเว็บอยู่ใน dist/
```

## วิธีเก็บค่าบริการ (คิดเป็นรายวัน)
1. ลูกค้าเลือกจำนวนวัน — ตั้งต้น **1 วัน 50 บาท** และ **3 วัน 100 บาท** (เพิ่ม/แก้ราคาได้ในหลังบ้าน → แพ็กเกจ) แล้วกรอกชื่อ เบอร์ LINE
2. ระบบแสดง QR PromptPay ตามยอด → ลูกค้าโอนแล้วแนบสลิปในเว็บ (หน้าจอแสดง "รอร้านยืนยัน" และเช็กสถานะเองทุก 10 วินาที)
3. แอดมินกด **อนุมัติและออกรหัส** ในหลังบ้าน → หน้าจอลูกค้าแสดง **รหัสเข้าใช้งาน 10 หลัก + QR สำหรับสแกน** ทันที
   (รหัสจะไม่ถูกเปิดเผยก่อนร้านยืนยันการชำระเงิน)
4. ลูกค้า **สแกน QR** (ลิงก์ `…/#login=รหัส`) หรือพิมพ์รหัสที่หน้า "เข้าใช้งาน" → เข้าหน้าออกแบบได้ทุกเครื่องจนครบจำนวนวัน
5. ซื้อเพิ่มวัน: ใช้รหัสเดิม วันใช้งานต่อจากวันหมดอายุเดิม แบบที่บันทึกไว้อยู่ครบ — ลูกค้าลืมรหัส แอดมินเปิดดูรหัส/QR ในหน้า "ลูกค้า" แล้วส่งให้ได้

**โหมดทดลองใช้** (เปิด/ปิดได้ในหลังบ้าน → ตั้งค่า): ใช้หน้าออกแบบได้ทุกอย่าง แต่ **บันทึกแบบ** และ **ส่งออกรูป** ต้องมีรหัสที่ใช้งานอยู่
ถ้าปิดโหมดทดลอง ต้องมีรหัสที่ใช้งานอยู่จึงจะเข้าหน้าออกแบบได้

## FORMA STUDIO (`/#studio`) — ออกแบบเฟอร์นิเจอร์
หนึ่งโปรเจกต์มีได้หลายชิ้น (เช่น ตู้ครัวทั้งชุด) · ทุกมุมมองคำนวณจากโมเดลเดียวกัน (`src/studio/model.js` → แผ่นไม้ทุกชิ้น)

| แท็บ | ทำอะไรได้ |
|---|---|
| **ออกแบบ 2D** | ภาพด้านหน้าตามสเกล · แบ่งช่อง (สูงสุด 8) · **ลากแผ่นกั้นซ้าย-ขวา** ปรับความกว้างช่อง · **ลากชั้นวาง / ลิ้นชัก / ราวแขวน จากแถบด้านบนไปวางในตู้** แล้วลากขึ้น-ลงได้ (แตะปุ่มเฉย ๆ = เพิ่มในช่องที่เลือก) · ชิ้นที่ทับกันขึ้นกรอบแดง · บอกระยะช่องว่างทุกช่อง · ประตูต่อช่อง: ไม่มี / บานซ้าย / บานขวา / บานคู่ / บานยก · ลิ้นชักในช่องที่มีบานเป็นลิ้นชักใน · ฐานบังโป๊ ท็อปเคาน์เตอร์ ความสูงติดตั้ง (ตู้แขวน) · วัสดุโครง/หน้าบาน/แผ่นหลัง และสีแยกกัน · ย้อนกลับ/ทำซ้ำ |
| **โมเดล 3D** | หมุน ซูม (นิ้ว/เมาส์) · **แตะบานหรือลิ้นชักเพื่อเปิด-ปิด** หรือปุ่มเปิดทั้งหมด · ดูทุกชิ้นเรียงกัน หรือเฉพาะชิ้นที่เลือก · บันทึกรูป PNG |
| **ใบตัดไม้** | รายการชิ้นส่วนแยกตามวัสดุ (ยาว × กว้าง × หนา, จำนวน, ด้านที่ปิดขอบ) · **จัดเรียงชิ้นงานบนแผ่นมาตรฐาน 120 × 240 ซม.** (เลือก 122 × 244 / 183 × 244 หรือกำหนดเองได้) เผื่อใบเลื่อย · เลือกหมุน/ไม่หมุนตามลายไม้ · บอกจำนวนแผ่น % การใช้เนื้อไม้ พื้นที่ ตร.ม. ระยะปิดขอบ · ภาพการตัดทุกแผ่น · ส่งออก CSV · **ใบตัดไม้ PDF** |
| **ราคา / ใบเสนอราคา** | แก้ราคาวัสดุต่อแผ่น เพิ่มวัสดุเอง · ปิดขอบ/เมตร บานพับ รางลิ้นชัก มือจับ ราวแขวน ขาเหล็ก ท็อป/เมตร ค่าแรง/แผ่น ค่าติดตั้ง กำไร % ส่วนลด VAT · สรุปต้นทุน ราคาขาย กำไร และราคาต่อชิ้น · **ใบเสนอราคา PDF** (ชื่อลูกค้า เลขที่ ยืนราคา มัดจำ หมายเหตุ ภาพแบบทุกชิ้น) |
| **วัดจากรูป** | อัปโหลดภาพ → ใส่ระยะอ้างอิง (เช่น 100 ซม.) → แตะสองจุดกำหนดสเกล → ลากกรอบครอบแต่ละชิ้น → ได้กว้าง × สูง พื้นที่ และต้นทุนวัสดุ · ย้าย/ปรับขนาดกรอบได้ · กด **สร้างเป็นตู้** เพื่อนำขนาดไปออกแบบต่อ |

แม่แบบ: ตู้เสื้อผ้า 2 บาน / 3 บาน+ลิ้นชัก, ชั้นหนังสือ, ตู้ทีวี, ตู้รองเท้า, ตู้เปล่า, ตู้ครัวล่างบานคู่ / ลิ้นชัก 3 ชั้น, ตู้ครัวแขวน, โต๊ะทำงาน, โต๊ะอาหารขาเหล็ก, เตียง 5 / 6 ฟุต
(ราคาวัสดุตั้งต้นเป็นราคาประมาณการ — แก้ในแท็บราคาให้ตรงกับร้านวัสดุ ค่าที่แก้ถูกเก็บในโปรเจกต์)

**หลายโปรเจกต์:** "โปรเจกต์ของฉัน" แสดงทั้งโปรเจกต์เฟอร์นิเจอร์และผังห้อง (กรอง/ค้นหาได้ สูงสุด 100 แบบต่อรหัส) · บันทึก/เปิดเป็นไฟล์ `.forma.json` ได้ · งานที่ทำค้างเก็บในเครื่องอัตโนมัติ

**สิทธิ์:** ใช้ได้ทุกฟีเจอร์ในโหมดทดลอง — **บันทึกบนคลาวด์ บันทึกไฟล์ ส่งออกรูป CSV ใบตัดไม้ และใบเสนอราคา** ต้องมีรหัสที่ใช้งานอยู่ ·
สแกน QR / ลิงก์ `#login=รหัส` จะเปิดหน้า FORMA STUDIO · PDF ออกโดยหน้าต่างพิมพ์ของเบราว์เซอร์ → เลือก "บันทึกเป็น PDF" (ตัวอักษรไทยคมชัด)

## หน้าจัดผังห้อง (`/#design`)
- กำหนดขนาดห้อง (ซม.) สีพื้น สีผนัง — แสดงขนาดและพื้นที่ ตร.ม.
- เฟอร์นิเจอร์/องค์ประกอบ 38 แบบ: ห้องนั่งเล่น ห้องนอน ครัว ห้องทำงาน ห้องน้ำ ประตู หน้าต่าง ผนังกั้น เสา ข้อความ
- ลากย้าย, ลากมุมปรับขนาด, ลากจุดด้านบนหมุน (ทีละ 15°, กด Shift หมุนอิสระ), พิมพ์ขนาด/ตำแหน่ง/องศาเอง
- เปลี่ยนสี ตั้งชื่อ ทำซ้ำ ลบ จัดชั้นบน/ล่าง, จับระยะ 5 ซม., เส้นตาราง 50 ซม., ย้อนกลับ/ทำซ้ำ
- ซูมด้วยล้อเมาส์หรือสองนิ้ว ลากพื้นที่ว่างเพื่อเลื่อน ใช้บนมือถือได้
- คีย์ลัด: R หมุน 90° · Delete ลบ · ลูกศรขยับ (Shift = 10 ซม.) · Ctrl+Z / Ctrl+Y · Ctrl+D ทำซ้ำ
- งานที่กำลังทำถูกเก็บในเครื่องอัตโนมัติ, บันทึกบนคลาวด์ได้สูงสุด 100 แบบต่อรหัส, ส่งออก PNG ความละเอียดสูง

## หลังบ้าน
- **รายรับรายเดือน** (สำหรับยื่นภาษี / ทำบัญชี): เลือกปี → รายรับทั้งปีเทียบปีก่อน, ค่าเฉลี่ยต่อเดือน, เดือนสูงสุด, กราฟ 12 เดือน,
  ตารางแยกตามแพ็กเกจ และเตือนรายการที่ไม่มีสลิป · เลือกเดือน → รายการทุกรายการพร้อมดูสลิป, ส่งออก CSV,
  **ดาวน์โหลดสลิปทั้งเดือนเป็น ZIP** (CSV + สลิปทุกใบ ชื่อไฟล์ `วันที่_เลขที่รายการ.jpg`), **พิมพ์รายงานประจำเดือน**, สรุปทั้งปีเป็น CSV
  (นับรายรับตามวันที่ร้านกดอนุมัติ เวลาประเทศไทย)
- **หลักฐานการชำระเงินเก็บถาวร**: สลิปลบจากระบบไม่ได้ (ไม่มีสิทธิ์ลบใน storage), ถ้าลูกค้าแนบสลิปใหม่ สลิปเดิมยังเก็บไว้,
  รายการชำระเงินลบไม่ได้ (เปลี่ยนได้แค่สถานะ) และลูกค้าที่เคยชำระเงินแล้วลบไม่ได้
- ภาพรวม: รายได้วันนี้/เดือนนี้, กราฟ 14 วัน, สลิปที่รอตรวจ, ลูกค้าที่ใช้งานอยู่
- การชำระเงิน: ดูสลิป อนุมัติ/ไม่อนุมัติ/ยกเลิกการอนุมัติ (หักวันคืน), ส่งออก CSV, แจ้งเตือนรายการใหม่ทันที
- ลูกค้า: ค้นหา ดูรหัส วันหมดอายุ จำนวนแบบ, เพิ่มวันใช้งานเอง (แถม/ชดเชย), ปิดสิทธิ์
- แพ็กเกจ: เพิ่ม/แก้ชื่อ จำนวนวัน ราคา คำอธิบาย, เปิด/ปิดขาย
- ตั้งค่า: ชื่อเว็บ เบอร์ LINE OA Facebook เวลาทำการ, PromptPay (พรีวิว QR), โหมดทดลองใช้

## ฐานข้อมูล (Supabase)
ใช้โปรเจกต์ Supabase เดียวกับ B2carrent (บัญชีฟรีสร้างได้สูงสุด 2 โปรเจกต์) แต่แยกข้อมูลกันชัดเจน:
ตาราง `furniture_*` และที่เก็บสลิป `furniture-slips` — ไม่แตะข้อมูลรถเช่า

- `supabase/schema.sql` — ตาราง, สิทธิ์ (RLS), ฟังก์ชันฝั่งเซิร์ฟเวอร์, ที่เก็บสลิป
- `supabase/setup.sql` — **ไฟล์เดียวรวม schema + seed** สำหรับวางใน SQL Editor แล้วกด Run
- `supabase/seed.sql` — ตั้งค่าเริ่มต้น + แพ็กเกจ 3 แบบ + ให้แอดมิน B2 เป็นแอดมินเว็บนี้ด้วย

**แอดมิน:** ล็อกอินด้วยอีเมล/รหัสผ่านเดียวกับหลังบ้าน B2 Rental ได้ทันที เพิ่มคนอื่นได้ด้วย
```sql
insert into public.furniture_admins (user_id) select id from auth.users where email = 'staff@example.com';
```

### ความปลอดภัย
- ราคาแพ็กเกจและวันหมดอายุคำนวณบนเซิร์ฟเวอร์ ลูกค้าแก้เองไม่ได้ วันใช้งานเพิ่มได้เฉพาะเมื่อแอดมินอนุมัติ
- บันทึกแบบตรวจสิทธิ์บนเซิร์ฟเวอร์ทุกครั้ง (รหัสหมดอายุ = บันทึกไม่ได้)
- รหัสสุ่ม 10 หลัก (~10^15 แบบ) เดาไม่ได้ — ลูกค้าลืมรหัส แอดมินค้นจากชื่อ/เบอร์ในหน้า "ลูกค้า" ได้
- สลิปเก็บแบบส่วนตัว เฉพาะแอดมินเปิดดูได้ · `anon key` ในโค้ดเปิดเผยได้ — **ห้าม** ใส่ `service_role key` ในหน้าเว็บ
