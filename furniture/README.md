# Furniture Design
เว็บออกแบบจัดวางเฟอร์นิเจอร์ภายในห้อง (เก็บค่าบริการการใช้งาน — ไม่ได้ขายสินค้า)

React 18 + Vite + Tailwind CSS + lucide-react + Supabase (โครงสร้างเดียวกับ B2carrent)

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # ไฟล์สำหรับขึ้นเว็บอยู่ใน dist/
```

## หน้าเว็บ
| ลิงก์ | หน้า |
|---|---|
| `/` | หน้าแรก: แนะนำบริการ ขั้นตอน ฟีเจอร์ แพ็กเกจราคา |
| `/#design` | หน้าออกแบบห้อง |
| `/#account` | ลูกค้าเข้าใช้งานด้วยรหัส ดูวันหมดอายุ แนบสลิป ต่ออายุ |
| `/#admin` | หลังบ้าน (ไม่มีปุ่มให้ลูกค้าเห็น — เปิดด้วยลิงก์นี้) |

## วิธีเก็บค่าบริการ (คิดเป็นรายวัน)
1. ลูกค้าเลือกจำนวนวัน — ตั้งต้น **1 วัน 50 บาท** และ **3 วัน 100 บาท** (เพิ่ม/แก้ราคาได้ในหลังบ้าน → แพ็กเกจ) แล้วกรอกชื่อ เบอร์ LINE
2. ระบบแสดง QR PromptPay ตามยอด → ลูกค้าโอนแล้วแนบสลิปในเว็บ (หน้าจอแสดง "รอร้านยืนยัน" และเช็กสถานะเองทุก 10 วินาที)
3. แอดมินกด **อนุมัติและออกรหัส** ในหลังบ้าน → หน้าจอลูกค้าแสดง **รหัสเข้าใช้งาน 10 หลัก + QR สำหรับสแกน** ทันที
   (รหัสจะไม่ถูกเปิดเผยก่อนร้านยืนยันการชำระเงิน)
4. ลูกค้า **สแกน QR** (ลิงก์ `…/#login=รหัส`) หรือพิมพ์รหัสที่หน้า "เข้าใช้งาน" → เข้าหน้าออกแบบได้ทุกเครื่องจนครบจำนวนวัน
5. ซื้อเพิ่มวัน: ใช้รหัสเดิม วันใช้งานต่อจากวันหมดอายุเดิม แบบที่บันทึกไว้อยู่ครบ — ลูกค้าลืมรหัส แอดมินเปิดดูรหัส/QR ในหน้า "ลูกค้า" แล้วส่งให้ได้

**โหมดทดลองใช้** (เปิด/ปิดได้ในหลังบ้าน → ตั้งค่า): ใช้หน้าออกแบบได้ทุกอย่าง แต่ **บันทึกแบบ** และ **ส่งออกรูป** ต้องมีรหัสที่ใช้งานอยู่
ถ้าปิดโหมดทดลอง ต้องมีรหัสที่ใช้งานอยู่จึงจะเข้าหน้าออกแบบได้

## หน้าออกแบบ
- กำหนดขนาดห้อง (ซม.) สีพื้น สีผนัง — แสดงขนาดและพื้นที่ ตร.ม.
- เฟอร์นิเจอร์/องค์ประกอบ 38 แบบ: ห้องนั่งเล่น ห้องนอน ครัว ห้องทำงาน ห้องน้ำ ประตู หน้าต่าง ผนังกั้น เสา ข้อความ
- ลากย้าย, ลากมุมปรับขนาด, ลากจุดด้านบนหมุน (ทีละ 15°, กด Shift หมุนอิสระ), พิมพ์ขนาด/ตำแหน่ง/องศาเอง
- เปลี่ยนสี ตั้งชื่อ ทำซ้ำ ลบ จัดชั้นบน/ล่าง, จับระยะ 5 ซม., เส้นตาราง 50 ซม., ย้อนกลับ/ทำซ้ำ
- ซูมด้วยล้อเมาส์หรือสองนิ้ว ลากพื้นที่ว่างเพื่อเลื่อน ใช้บนมือถือได้
- คีย์ลัด: R หมุน 90° · Delete ลบ · ลูกศรขยับ (Shift = 10 ซม.) · Ctrl+Z / Ctrl+Y · Ctrl+D ทำซ้ำ
- งานที่กำลังทำถูกเก็บในเครื่องอัตโนมัติ, บันทึกบนคลาวด์ได้สูงสุด 100 แบบต่อรหัส, ส่งออก PNG ความละเอียดสูง

## หลังบ้าน
- ภาพรวม: รายได้วันนี้/เดือนนี้, กราฟ 14 วัน, สลิปที่รอตรวจ, ลูกค้าที่ใช้งานอยู่
- การชำระเงิน: ดูสลิป อนุมัติ/ไม่อนุมัติ/ยกเลิกการอนุมัติ (หักวันคืน), ส่งออก CSV, แจ้งเตือนรายการใหม่ทันที
- ลูกค้า: ค้นหา ดูรหัส วันหมดอายุ จำนวนแบบ, เพิ่มวันใช้งานเอง (แถม/ชดเชย), ปิดสิทธิ์
- แพ็กเกจ: เพิ่ม/แก้ชื่อ จำนวนวัน ราคา คำอธิบาย, เปิด/ปิดขาย
- ตั้งค่า: ชื่อเว็บ เบอร์ LINE OA Facebook เวลาทำการ, PromptPay (พรีวิว QR), โหมดทดลองใช้

## ฐานข้อมูล (Supabase)
ใช้โปรเจกต์ Supabase เดียวกับ B2carrent (บัญชีฟรีสร้างได้สูงสุด 2 โปรเจกต์) แต่แยกข้อมูลกันชัดเจน:
ตาราง `furniture_*` และที่เก็บสลิป `furniture-slips` — ไม่แตะข้อมูลรถเช่า

- `supabase/schema.sql` — ตาราง, สิทธิ์ (RLS), ฟังก์ชันฝั่งเซิร์ฟเวอร์, ที่เก็บสลิป
- `supabase/seed.sql` — ตั้งค่าเริ่มต้น + แพ็กเกจ 3 แบบ + ให้แอดมิน B2 เป็นแอดมินเว็บนี้ด้วย

**แอดมิน:** ล็อกอินด้วยอีเมล/รหัสผ่านเดียวกับหลังบ้าน B2 Rental ได้ทันที เพิ่มคนอื่นได้ด้วย
```sql
insert into public.furniture_admins (user_id) select id from auth.users where email = 'staff@example.com';
```

### ความปลอดภัย
- ราคาแพ็กเกจและวันหมดอายุคำนวณบนเซิร์ฟเวอร์ ลูกค้าแก้เองไม่ได้ วันใช้งานเพิ่มได้เฉพาะเมื่อแอดมินอนุมัติ
- บันทึกแบบตรวจสิทธิ์บนเซิร์ฟเวอร์ทุกครั้ง (รหัสหมดอายุ = บันทึกไม่ได้)
- รหัสสุ่ม 10 หลัก (~10^15 แบบ) เดาไม่ได้ — ลูกค้าลืมรหัส แอดมินค้นจากชื่อ/เบอร์ในหน้า "ลูกค้า" ได้
- สลิปเก็บแบบส่วนตัว เฉพาะแอดมินเปิดดูได้ · `anon key` ในโค้ดเปิดเผยได้ — **ห้าม** ใส่ `service_role key` ในหน้าเว็บ
